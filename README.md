# README

# Instalación del DevContainer

Este proyecto está configurado para usarse con un DevContainer en Visual Studio Code, lo que permite un entorno de desarrollo consistente y listo para trabajar.

# Requisitos

-  Visual Studio Code instalado.
-  Extensión Remote - Containers instalada en VSCode.
-  Docker instalado y ejecutándose en tu máquina.

# Pasos para usar el DevContainer

-  Clona el repositorio: git clone https://github.com/JBI91/dev_project_robot.git.
-  Abre Visual Studio Code.
-  Abre la carpeta del proyecto clonada (dev_project_robot).
-  Aparecerá una ventana emergente (o usar el comando de paleta) para Reabrir en contenedor.
-  Usa la paleta de comandos (Ctrl+Shift+P o Cmd+Shift+P) y ejecuta:  Remote-Containers: Reopen in Container
-  VSCode construirá y levantará el entorno de desarrollo según la configuración del DevContainer.

Una vez dentro, tendrás el entorno listo con todas las dependencias y configuraciones necesarias para comenzar la visualización del proyecto.
